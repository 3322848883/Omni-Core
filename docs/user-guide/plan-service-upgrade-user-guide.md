## 概述

套餐服务体系升级（v2.0）引入了多项重要改进，包括：

- **套餐组概念**：将套餐按类型分组，便于用户选择
- **IP池管理**：支持动态IP分配和轮换
- **服务类型权益**：不同服务类型提供不同的服务质量
- **IP声誉检测**：自动检测IP质量，确保服务稳定性

## 新功能介绍

### 1. 套餐组

套餐现在分为四个主要组别：

| 套餐组 | 说明 | 适用场景 |
|--------|------|----------|
| **机场大流量套餐** | 大流量机房节点 | 下载、视频观看、日常代理 |
| **专线加速套餐** | 高质量专线，低延迟 | 游戏加速、视频流媒体、高频交易 |
| **住宅IP套餐** | 真实家庭宽带IP | 流媒体解锁、账号注册、防追踪 |
| **独享IP套餐** | 独立IP资源 | 企业用户、IP敏感业务、高安全需求 |

### 2. 服务类型

系统支持三种服务类型：

| 服务类型 | 优先级 | 特点 |
|----------|--------|------|
| **标准服务** | 1 | 大流量、多节点、基础速度 |
| **专线服务** | 2 | CN2/IEPL专线、低延迟、高稳定 |
| **独享服务** | 3 | 独立IP、IPLC专线、企业级 |

### 3. IP池管理

IP池支持以下功能：

- **动态IP分配**：根据策略自动分配IP
- **IP轮换**：支持多种轮换策略
- **IP评分**：自动检测IP质量
- **IP封禁**：自动封禁低质量IP

### 4. 轮换策略

IP池支持四种轮换策略：

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| **轮询** | 按顺序循环使用IP | 均衡使用所有IP |
| **随机** | 随机选择IP | 避免固定模式 |
| **最少使用** | 优先选择使用次数最少的IP | 均衡负载 |
| **质量优先** | 优先选择评分最高的IP | 保证服务质量 |

## 套餐管理

### 创建套餐

1. 登录管理后台
2. 进入"套餐管理"页面
3. 点击"创建套餐"按钮
4. 填写套餐信息：
   - **基本信息**：名称、描述、价格、时长
   - **套餐组**：选择所属套餐组
   - **服务类型**：选择支持的服务类型
   - **权益配置**：流量限制、连接数、带宽等
   - **特性列表**：套餐包含的功能特性
5. 点击"保存"

### 套餐字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 名称 | 套餐显示名称 | 基础套餐 |
| 描述 | 套餐详细说明 | 适合日常使用的经济型套餐 |
| 套餐组 | 所属套餐组 | 机场大流量套餐 |
| 价格 | 套餐价格（USD） | 9.99 |
| 时长 | 套餐有效期（天） | 30 |
| 流量限制 | 每月可用流量（字节） | 107374182400 (100GB) |
| 服务类型 | 支持的服务类型 | 标准服务 |
| 优先级提升 | 连接优先级提升值 | 0 |
| 保证带宽 | 保证的最小带宽（Mbps） | 0 |
| 最大连接数 | 同时在线设备数 | 3 |
| 特性列表 | 套餐包含的功能 | ["标准线路", "100GB流量"] |

### 编辑套餐

1. 在套餐列表中找到要编辑的套餐
2. 点击"编辑"按钮
3. 修改需要更新的字段
4. 点击"保存"

**注意**：
- 修改价格不会影响已购买的订阅
- 修改服务类型需要谨慎，可能影响现有用户

### 删除套餐

1. 在套餐列表中找到要删除的套餐
2. 点击"删除"按钮
3. 确认删除

**注意**：
- 有活跃订阅的套餐不能删除
- 删除后，已购买的订阅仍然有效直到过期

### 套餐统计

查看套餐统计数据：

1. 在套餐列表中点击套餐名称
2. 查看"统计"标签页
3. 查看以下数据：
   - 总订阅数
   - 活跃订阅数
   - 总收入
   - 用户留存率
   - 增长趋势

## IP池管理

### 创建IP池

1. 进入"IP池管理"页面
2. 点击"创建IP池"按钮
3. 填写IP池信息：
   - **名称**：IP池名称
   - **关联节点**：选择关联的节点
   - **IP类型**：选择IP类型
   - **IP列表**：输入IP地址（每行一个）
   - **轮换策略**：选择轮换策略
   - **轮换间隔**：设置轮换间隔（秒）
4. 点击"创建"

### IP类型说明

| IP类型 | 说明 | 特点 |
|--------|------|------|
| **机房IP** | 数据中心IP | 大带宽、稳定、成本低 |
| **动态住宅IP** | 动态家庭宽带IP | 真实用户IP、适合解锁 |
| **静态住宅IP** | 固定家庭宽带IP | 固定IP、适合长期业务 |
| **移动IP** | 移动网络IP | 移动网络、高匿名性 |

### 管理IP池

#### 查看IP池详情

1. 在IP池列表中点击IP池名称
2. 查看以下信息：
   - IP池基本信息
   - IP列表及状态
   - 当前使用IP
   - 轮换历史

#### 添加IP

1. 在IP池详情页点击"添加IP"
2. 输入IP地址
3. 系统自动检测IP评分
4. 点击"确认"

#### 移除IP

1. 在IP列表中找到要移除的IP
2. 点击"移除"按钮
3. 确认移除

#### 手动轮换

1. 在IP池详情页点击"手动轮换"
2. 系统立即切换到下一个IP
3. 查看轮换结果

#### 刷新IP评分

1. 在IP池详情页点击"刷新评分"
2. 系统重新检测所有IP的评分
3. 查看更新后的评分

### IP状态说明

| 状态 | 说明 | 操作 |
|------|------|------|
| **活跃** | IP正常可用 | 可分配给用户 |
| **已分配** | IP正在使用中 | 等待释放 |
| **已封禁** | IP评分过低 | 需检查或移除 |
| **非活跃** | IP暂时不可用 | 可重新激活 |

## 常见问题

### Q1: 如何选择合适的套餐组？

**A**: 根据使用场景选择：

- **大流量下载/视频观看** → 机场大流量套餐
- **游戏加速/低延迟需求** → 专线加速套餐
- **流媒体解锁/账号注册** → 住宅IP套餐
- **企业用户/高安全需求** → 独享IP套餐

### Q2: IP轮换会影响正在使用的连接吗？

**A**: 不会。IP轮换只影响新连接，现有连接会保持直到断开。建议在低峰期进行手动轮换。

### Q3: IP评分是如何计算的？

**A**: IP评分基于以下因素：

- **威胁检测**：是否被标记为代理/VPN/Tor
- **滥用记录**：是否有滥用投诉
- **地理位置**：IP所在地区
- **ISP类型**：住宅ISP评分高于数据中心

评分范围：0-100，建议只使用评分>=70的IP。

### Q4: 套餐可以修改服务类型吗？

**A**: 可以，但需要谨慎：

- 修改后，新购买的订阅会使用新的服务类型
- 现有订阅保持原有服务类型直到过期
- 建议提前通知用户服务变更

### Q5: 如何查看套餐的销售情况？

**A**: 

1. 进入套餐详情页
2. 点击"统计"标签
3. 查看以下数据：
   - 总订阅数
   - 活跃订阅数
   - 总收入
   - 月增长率
   - 用户留存率

### Q6: IP池的轮换策略如何选择？

**A**: 

- **轮询**：适合IP质量相近的场景
- **随机**：适合需要避免固定模式的场景
- **最少使用**：适合需要均衡负载的场景
- **质量优先**：适合对IP质量要求高的场景

### Q7: 如何处理被封禁的IP？

**A**: 

1. 检查IP评分和封禁原因
2. 如果是误判，可以重新激活
3. 如果确实有问题，建议移除并更换新IP
4. 定期清理低质量IP，保持IP池健康

### Q8: 套餐组可以自定义吗？

**A**: 目前系统预定义了四个套餐组，暂时不支持自定义。如有特殊需求，请联系技术支持。

### Q9: 如何设置套餐的排序？

**A**: 

1. 进入套餐列表
2. 点击"排序"按钮
3. 拖拽调整套餐顺序
4. 点击"保存"

排序会影响套餐在前端的展示顺序。

### Q10: 服务类型的优先级有什么作用？

**A**: 优先级用于：

- **连接调度**：高优先级服务优先分配资源
- **带宽保障**：高优先级服务获得更大带宽份额
- **故障恢复**：高优先级服务优先恢复

优先级数值越大，优先级越高。

## 最佳实践

### 套餐设计

1. **明确定位**：每个套餐组有明确的目标用户
2. **差异化定价**：不同套餐组有明显的价格差异
3. **权益清晰**：套餐权益描述清晰易懂
4. **定期优化**：根据数据调整套餐配置

### IP池管理

1. **定期检测**：定期刷新IP评分，及时发现问题IP
2. **合理轮换**：根据业务需求选择合适的轮换策略
3. **质量优先**：保持IP池质量，及时移除低分IP
4. **监控告警**：设置IP质量告警，及时处理异常

### 服务类型配置

1. **节点分布**：不同服务类型配置不同节点
2. **带宽规划**：根据用户需求合理分配带宽
3. **优先级设置**：重要服务设置更高优先级
4. **监控指标**：关注各服务类型的性能指标
